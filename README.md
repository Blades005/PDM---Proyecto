# PDM---Proyecto
Repositorio de Proyecto PDM del grupo 1 Ciclo I 2025
## Descripción  
Este repositorio contiene el desarrollo del **Proyecto PDM** del grupo 1 del **Ciclo I 2025**. Se trata de una plataforma enfocada en la gestión y reserva de actividades turísticas en destinos exóticos, optimizando la experiencia para turistas y proveedores mediante un sistema eficiente e intuitivo.  

## Características del Proyecto  
- Sistema de reservas online con exploración y filtrado por destino, fecha y categoría.  
- Gestión de usuarios, incluyendo perfiles, historial de reservas y notificaciones.  
- Administración de actividades por parte de proveedores con herramientas intuitivas.  
- Seguridad en pagos mediante integración con pasarelas de pago confiables.  
- Panel de administración para gestión de usuarios, actividades y datos generales.  

## Tecnologías Utilizadas  
- Kotlin (Desarrollo en Android)  
- SQLite (Base de datos local)  
- Android Studio  
- GitHub (Control de versiones)
